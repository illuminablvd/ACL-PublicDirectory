# AI Creator Labs — Learning Portal

Portal statis tanpa build step. Jalankan preview lokal dari folder ini:

```sh
python3 preview_server.py
```

Buka `http://localhost:4173`. Untuk hosting static, arahkan document root ke folder ini. Preview server dan aturan `_redirects` menyediakan fallback route agar `/resources`, `/knowledges`, `/articles`, dan `/skills` tetap bekerja saat dibuka langsung.

Konten artikel saat ini berupa catatan awal yang ditulis untuk prototipe. Video mengarah ke kanal AI Creator Labs karena URL video individual dan durasinya belum diverifikasi.

Lihat [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) untuk progres, keputusan desain, batasan, dan pekerjaan berikutnya.
